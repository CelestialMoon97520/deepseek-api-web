# DeepSeek_API 网页版 1.0.8

基于 [DeepSeek chat-demo](https://github.com/deepseek-ai/chat-demo) 的非官方浏览器客户端。每位用户使用自己的 DeepSeek 开放平台 API Key。此目录可作为静态站点根目录部署到 GitHub Pages，入口为 `index.html`。

## 1.0.8 更新

设置中新增「字体大小」：可跟随系统字体大小，或在五档滑杆中调整界面文字大小，设置保存在本机。网页端的「跟随系统」使用浏览器默认字号，不覆盖用户自己的浏览器设置。文字缩放后输入区仍保持单行，两个开关的名称在空间不足时右侧渐隐。此项目维护网页版和 Android APK。

保留快速和专家模式、流式回答、聊天历史搜索和 ZIP 导入导出。输入新消息和编辑旧消息时，回车换行，通过「发送」按钮提交。网页使用对话气泡图标，并在聊天区提供[使用和数据说明](about.html)。

安卓原生凭据保护和系统返回手势依赖 Android。网页遵循上游的存储方式，API Key 和设置保存在浏览器 localStorage，聊天和附件保存在 IndexedDB。网页代码使用 Key 向 `api.deepseek.com` 直接鉴权。第一方网页脚本和有权读取站点存储的扩展可能访问 Key。聊天、文件、转写和朗读数据按需发送给 DeepSeek，调用费用由 Key 所属账号承担。用户可在开放平台单独创建和撤销 Key。

浏览器版只托管静态网页资源。项目没有 API 中转、云同步或遥测，服务器侧的数据处理见 DeepSeek 开放平台隐私政策。浏览器资料和站点源隔离各自的数据。同一浏览器也可能在清除站点数据后丢失本地会话，重要记录请导出 ZIP。已经托管过的旧版在同一地址使用相同的存储名称。

## 来源与许可证

网页沿用与 Android 1.0.6 对应的聊天前端和回车行为，应用 1.0.7 的开关样式与 1.0.8 的字号设置。构建过程中复用的 [chat-demo](https://github.com/deepseek-ai/chat-demo) 及衍生代码在 `SOURCES.txt` 和随包许可证中列明。上游 MIT 版权和许可声明保留。第三方组件遵循各自的许可证。内容由 AI 生成，请核实重要信息。
