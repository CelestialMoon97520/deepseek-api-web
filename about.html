DeepSeek_API 网页版

这是基于 DeepSeek 开源 chat-demo 的非官方项目。回复由 AI 生成，请核实重要内容。软件按 MIT 许可证原样提供。

API Key 和费用

请使用自己的 DeepSeek 开放平台 API Key。请求直接发往 DeepSeek，费用计入你的开放平台账号。网页代码会读取 Key 来发送请求，浏览器内可访问该站点数据的脚本也可能读取它。可以为此项目单独创建一个 Key，并在开放平台查看用量或撤销。

数据保存位置

Key 和设置保存在当前浏览器的 localStorage。会话和附件保存在 IndexedDB。换浏览器、设备或站点地址时，需要重新录入 Key，并可用聊天 ZIP 迁移会话。清除站点数据可能删除本地记录。

哪些数据会联网

GitHub Pages 提供静态网页文件。网页没有作者运营的 API 中转、聊天云同步或遥测。发送消息、上传附件、语音转写和朗读时，相应数据会传给 DeepSeek。对话中的外部图片也可能由浏览器直接加载。

聊天 ZIP 包含会话及可用的本地图片，排除单独保存的 Key、应用设置和非图片附件原件。直接写在消息里的内容仍会随会话导出。确认导入前请先备份当前聊天，导入会替换本地会话。
